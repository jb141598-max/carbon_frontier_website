MediaWiki Template Wikitext

This editor accepts normal Miraheze/MediaWiki template source, including <includeonly>, <noinclude>, numbered or named {{{parameters}}}, nested Carbon Frontier templates, styled HTML, internal links, images, and safe parser functions.

Supported parser functions currently include #if, #ifeq, #switch, and arithmetic #expr. Nested template names must match a template in this Template Studio.

Use Apply & Preview to render the source. For safety, scripts, event handlers, unsafe links, and dangerous CSS are removed.
